# CineTime Frontend

Next.js App Router based frontend for CineTime cinema ticket booking.

## First Run

```powershell
npm install
npm run dev
```

Open:

```text
http://localhost:3000
```

Backend default:

```text
http://localhost:8081
```

## Learning Order

1. Read `app/layout.jsx`.
2. Read `helpers/config.js` and `helpers/api-routes.js`.
3. Read `services/api-client.js`.
4. Open `app/page.jsx` and `components/home/Hero.jsx`.
5. Then continue with login, movies, showtimes and seat selection.
